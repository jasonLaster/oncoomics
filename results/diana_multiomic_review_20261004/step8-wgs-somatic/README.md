# step8-wgs-somatic

This directory holds the somatic SNV, indel and SV calls from subject01's tumor/normal WGS, plus their signatures and TMB. It is for research prioritization only and is not a clinical result. It is private and gitignored; do not copy it into tracked files.

The full write-up is in `wgs_somatic_report.md`.

## Deliverables (top level)

| file | content |
|---|---|
| `wgs_somatic_report.md` | the report: controls, Serova concordance, TMB, SBS3, SVs, clonality, cost |
| `consensus_pass.vcf.gz` (+ `.tbi`) | Mutect2 PASS ∩ Strelka2 PASS, matched on exact normalized allele. Uses the Mutect2 records, with `STRELKA_AF` and `STRELKA_EVS` added |
| `consensus_pass_summary.tsv` | counts per caller and per set, Ti/Tv, per-Mb rate, median VAF |
| `sv_summary.tsv` | Manta PASS events by class and size, with microhomology counts |
| `signatures.csv` | SigProfilerAssignment fit (COSMIC v3.5) with 200-replicate bootstrap, plus a fixed-set NNLS cross-check |
| `cost_ledger.csv` | per-instance cloud cost, regenerated by `scripts/ledger.py` |

## Supporting files

- `results/final/`
  - `controls.tsv`
  - `serova_concordance.tsv`
  - `qc.json` (callable territory, contamination, filter counts, orientation)
  - `extras.json` (VAF quantiles)
  - `vaf_hist.tsv`
  - `sbs96_matrix.tsv`
  - `signatures/` (SPA output, `sbs96.png`, `sbs3_sensitivity.txt`, `signature_summary.json`)
  - `consensus_deletions_mh.tsv` and `indel_mh_summary.json`
  - `sv_pass.tsv`
  - `clonality_vs_step5.json`
- `results/cloud/`: small result files downloaded from S3 and verified against their SHA-256 manifests.
  - `mutect2/`: gathered and filtered VCFs, contamination, callable totals
  - `strelka/`
  - `manta/`
  - `in/`: symlinks used as the `analysis.py --indir`
- `results/serova_missense_sites.tsv`: the 22 Serova missense sites, extracted from the vendor read-evidence PDF, with exome and tumour-genome counts.
- `results/controls_sites_ext.tsv`: `controls_sites.tsv` plus TP53 c.559+2T>G.
- `results/shards_n192.tsv`: the shard plan.
- `results/signature_known_answer/`: synthetic SBS3-positive and SBS3-negative tests.

## Reproduce the local part

All of this runs on a Mac and reads only the small files above.

```
# presigned reference URL (current version verified == frozen VersionId) -> $REFURL_FILE; fai from the freeze
python3 scripts/analysis.py --indir results/cloud/in --outdir results/final --ref-url-file $REFURL_FILE --fai reference.fa.fai --controls results/controls_sites_ext.tsv
python3 scripts/sv_summary.py results/cloud/manta/somaticSV.vcf.gz results/final   # supersedes analysis.py SV section
python3 scripts/extras.py --indir results/cloud/in --outdir results/final --serova results/serova_missense_sites.tsv
python3 scripts/indel_mh.py results/final/consensus_pass.vcf.gz $REFURL_FILE reference.fa.fai results/final/consensus_deletions_mh.tsv
<spa-venv>/bin/python scripts/sig_fit.py --matrix results/final/sbs96_matrix.tsv --out results/final/signatures --boot 200
<spa-venv>/bin/python scripts/clonality.py results/final/consensus_pass.vcf.gz ../step5-ascn/segments_fit_S1b_p0.35_ploidy2.80.standardized.tsv results/final/clonality_vs_step5.json
```

`<spa-venv>` is a Python venv with SigProfilerAssignment 1.1.4, pandas and scipy. The one used here was built by the first agent in its session scratchpad; it is not stored in this directory.
